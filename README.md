# 두 개의 하늘, 하나의 여정

대한항공과 아시아나항공의 통합 과정을 기록한 독립 에디토리얼 웹진입니다.

- 공개 주소: <https://ideas1004.github.io/korean-air-asiana-webzine/>
- 발행일: 2026.08.19
- 기사 아카이브: 총 40개
- 승무원 관련 기사: 10개

## 구성

- 합병 타임라인과 핵심 수치
- 브랜드·CI, 노선·기재, 마일리지와 고객 영향
- 조직문화와 승무원 현장
- 국내외 경쟁당국의 승인 조건
- 기사 검색과 주제별 필터
- 모바일·태블릿·데스크톱 반응형 디자인

모든 기사 카드는 각 언론사 또는 공식 기관의 원문으로 연결됩니다. 기사 본문과 원문 이미지는 복제하지 않고 자체 작성한 짧은 요약과 링크만 제공합니다.

## 로컬에서 보기

`index.html`을 열거나 정적 파일 서버에서 프로젝트 루트를 제공하면 됩니다. 별도의 빌드 과정이나 서버 기능은 필요하지 않습니다.

`assets/images`를 포함한 디렉터리 구조를 유지해야 이미지와 스타일이 정상적으로 표시됩니다.

## 배포

`main` 브랜치에 변경 사항을 올리면 `.github/workflows/deploy-pages.yml`이 GitHub Pages 배포를 실행합니다. 동일한 정적 파일 구조로 Netlify와 Vercel에도 배포할 수 있습니다.
